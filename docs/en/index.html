Install Windows 10 as a dual-boot from Linux, without a USB drive

linwin makes room on the disk, copies the installer, boots it once and installs Windows unattended. It then comes back to Linux and adds Windows to your boot menu. Free software, for any distribution.

Download v1 Source code

What linwin does

No USB stick

A temporary FAT32 partition replaces the USB drive. It is deleted at the end and its space goes to Windows.

Zero interaction

Windows installs itself, creates your local account and reboots into Linux, which finishes the job.

Linux stays safe

Partitions go into free space, or a Btrfs root (even LUKS-encrypted) is shrunk online. Every step is verified.

Drivers included

Intel RST/VMD so the installer sees the SSD, plus Wi-Fi and Ethernet drivers from the Microsoft Update Catalog.

Your boot loader

Windows is added to GRUB, systemd-boot, Limine or rEFInd; Linux stays the default.

Reversible

linwin cancel removes Windows at any step and gives the space back to Linux.

Install

git clone https://github.com/2Deathadder/linwin.git
cd linwin
sudo ./linwin install
linwin check

Then open linwin from your application menu, or use the command line:

  1. sudo linwin prepare --size 100G — creates the Windows partitions
  2. sudo linwin stage --iso Win10.iso --edition Home --user me — copies the installer
  3. sudo linwin boot and reboot — Windows installs itself
  4. Back in Linux, linwin finishes (Windows appears in the boot menu)

Back up your data and keep the charger plugged in: linwin edits the partition table. The interface and messages are in French.

FAQ

Can I install Windows 10 from Linux without a USB drive?

Yes. linwin creates a small FAT32 partition that acts as the USB stick, copies the Windows 10 ISO to it and schedules a one-time boot.

Will linwin erase Linux?

No. It uses unallocated space, or shrinks a Btrfs root with checks at every step, and the installer may only write to the planned partition. A backup is still recommended.

My root filesystem is ext4. Is it possible?

Yes, if the disk has enough unallocated space. ext4 and XFS cannot be shrunk while Linux is running: free some space first (for example with GParted from a live system).

The Windows installer does not see my SSD (Intel VMD/RST)

linwin detects Intel VMD and adds the Intel RST driver to the installer automatically. No BIOS change is needed.

Will Wi-Fi work in Windows?

Yes: linwin adds the Windows 10 driver for each Wi-Fi and Ethernet card from the Microsoft Update Catalog (Intel, MediaTek, Realtek…).

How do I remove Windows later?

sudo linwin cancel removes Windows, its boot entries and partitions, then gives the space back to Linux.
