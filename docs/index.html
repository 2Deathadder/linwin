Installer Windows 10 en dual-boot depuis Linux, sans clé USB

linwin fait la place sur le disque, copie l'installeur, démarre dessus une seule fois et installe Windows sans intervention. Il revient ensuite sous Linux et ajoute Windows au menu de démarrage. Libre, pour toutes les distributions.

Télécharger linwin Lire le manuel

Ce que fait linwin

Sans clé USB

Une partition FAT32 temporaire remplace la clé USB. Elle est supprimée à la fin et son espace rendu à Windows.

Zéro intervention

Windows s'installe, crée ton compte local et redémarre sous Linux, qui finalise tout seul.

Linux préservé

Partitions créées dans l'espace libre, ou réduction à chaud d'une racine Btrfs (même chiffrée LUKS). Chaque étape est vérifiée.

Pilotes ajoutés

Intel RST/VMD pour que l'installeur voie le SSD, pilotes Wi-Fi et Ethernet du catalogue Microsoft Update.

Ton chargeur

Windows ajouté au menu de GRUB, systemd-boot, Limine ou rEFInd ; Linux reste le choix par défaut.

Réversible

linwin cancel retire Windows à n'importe quelle étape et rend l'espace à Linux.

Installation

git clone https://github.com/2Deathadder/linwin.git
cd linwin
sudo ./linwin install
linwin check

Puis lance linwin depuis le menu des applications, ou en ligne de commande :

  1. sudo linwin prepare --size 100G — crée les partitions de Windows
  2. sudo linwin stage --iso Win10.iso --edition Home --user moi — copie l'installeur
  3. sudo linwin boot puis redémarre — Windows s'installe tout seul
  4. Au retour sous Linux, linwin finalise (Windows apparaît dans le menu de démarrage)

Sauvegarde tes données et garde le chargeur branché : linwin modifie la table de partitions.

Questions fréquentes

Peut-on installer Windows 10 depuis Linux sans clé USB ?

Oui. linwin crée une petite partition FAT32 qui joue le rôle de la clé USB, y copie l'ISO de Windows 10 et programme un démarrage unique dessus.

linwin efface-t-il Linux ?

Non. Il utilise l'espace non alloué, ou réduit une racine Btrfs avec des vérifications à chaque étape, et l'installeur ne peut écrire que sur la partition prévue. Une sauvegarde reste recommandée.

Ma racine est en ext4 : est-ce possible ?

Oui, s'il y a assez d'espace non alloué sur le disque. ext4 et XFS ne se réduisent pas pendant que Linux tourne : libère d'abord de l'espace (par exemple avec GParted depuis un système live).

L'installeur Windows ne voit pas mon SSD (Intel VMD/RST)

linwin détecte Intel VMD et ajoute automatiquement le pilote Intel RST à l'installeur. Rien à changer dans le BIOS.

Aurai-je le Wi-Fi sous Windows ?

Oui : linwin ajoute le pilote Windows 10 de chaque carte Wi-Fi et Ethernet depuis le catalogue Microsoft Update (Intel, MediaTek, Realtek…).

Comment retirer Windows ensuite ?

sudo linwin cancel supprime Windows, ses entrées de démarrage et ses partitions, puis rend l'espace à Linux.
